# Расширение BeatDesk

Подставляет данные бита в формы BeatStars и BeatChain. **Ничего не публикует сама** — кнопку публикации нажимаешь ты. Это осознанное ограничение: расширение, которое жмёт «Опубликовать», быстро превращается в инструмент массового спама, и площадки блокируют аккаунт.

## Сборка

```bash
pnpm install --ignore-workspace
pnpm build
```

## Установка

1. `chrome://extensions`
2. Включить «Режим разработчика»
3. «Загрузить распакованное расширение» → папка `extension/dist`

## Как пользоваться

Основной путь — с самой страницы бита в BeatDesk:

1. Открыть бит и нажать «Открыть и заполнить» под нужной площадкой.
2. Расширение откроет (или подсветит уже открытую) вкладку формы.
3. Через несколько секунд поля заполнятся, а на странице площадки появится отчёт, что именно встало.
4. Проверить глазами и опубликовать самому.

Если кнопки на сайте нет, работает ручной путь через иконку расширения: открыть форму, кликнуть по иконке, вставить ссылку вида `https://beat-desk.vercel.app/beats/<id>`, «Загрузить бит», «Заполнить форму на этой вкладке».

Для этого у расширения должен быть включён `NEXT_PUBLIC_BEATDESK_EXTENSION_ID` в сборке сайта — без него сообщение с сайта некуда отправлять.

## Устройство

| Файл | Роль |
|---|---|
| `src/background.ts` | service worker: ловит сообщение с сайта, открывает вкладку площадки, забирает данные бита и внедряет content script |
| `src/content.ts` | content script: только заполнение формы на странице площадки |
| `src/filler.ts` | разбор страницы и подстановка значений |
| `src/fields.ts` | какие поля заполнять и какими словами их узнавать |

Сообщение с сайта приходит **только** в service worker: в content script внешние сообщения не доходят, а `chrome.tabs` и `chrome.scripting` там недоступны. Поэтому открытие вкладки живёт в фоне, а в content script — только работа с формой.

## Что заполняется на каждой площадке

Проверено на макетах, повторяющих реальные формы.

| Поле | BeatStars Studio | BeatChain |
|---|---|---|
| Название | да, до 60 символов | да, до 30 символов — обрезается |
| Описание | да | нет такого поля |
| BPM | да | да |
| Тональность | да, списком в формате `G#m` | да, списком |
| Теги | да, чипами — вводятся настоящим набором с Enter | да, одной строкой через запятую |
| Цены | да, если валюта бита USD | да, если валюта бита RUB |

## Почему цены ставятся не всегда

Валюта выбирается у бита: `RUB`, `USD` или `EUR`. Конвертации нет намеренно — курс меняется, а у трека цена должна быть зафиксирована, иначе одна и та же работа будет продаваться за разные суммы.

Поэтому цены подставляются только когда валюта бита совпадает с той, что ждёт форма: BeatStars показывает доллары, BeatChain — рубли. Бит в евро на обеих площадках останется без цены, и расширение скажет об этом прямо, а не поставит `$25.00` в поле, где ждут рубли.

## Как оно находит поля

Жёстких селекторов нет намеренно: формы перерисовываются, и любой зашитый селектор протухает. Поле узнаётся по подписи, `name`, `id`, `placeholder` и `aria-label` — по совпадению со словарём (`bpm`, `тональность`, `mp3`, `exclusive` и т.п.).

Если поле найти не удалось или цена не задана, расширение сообщает об этом списком, а не молча ничего не делает. Значения подсвечиваются по контуру на 6 секунд.

Файлы не подставляются: наши мастера лежат нетегированными, и автозагрузка привела бы к неверному названию бита на площадке.

## Где менять

- `src/fields.ts` — какие поля заполнять и какими словами их узнавать.
- `src/filler.ts` — сам разбор страницы и подстановка значений.
- `src/background.ts` — адреса форм и разговор с сайтом.

Airbit в автозаполнении не участвует: у него своя вёрстка, под которую надо отдельно проверять селекторы. Пока его форма не разобрана, на сайте он открывается обычной ссылкой.
